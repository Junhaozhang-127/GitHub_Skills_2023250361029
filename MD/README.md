## 使用说明

本仓库用于保存 GitHub Skills 课程 6 次上机实验报告。所有实验报告均使用 Markdown 编写，可以使用 Typora 打开查看，并通过“文件—导出—PDF”导出为 PDF 文件。

为便于提交和归档，仓库中保留了根目录下的原始 Markdown 文件，同时在 `MD/` 文件夹中放置了一份 Markdown 文档副本，在 `PDF/` 文件夹中按实验课次放置单独导出的 PDF 文档：

- `MD/`：Markdown 源文件归档副本
- `PDF/`：每一节实验报告对应一个独立 PDF 文件
- `assets/`：报告中使用的概念图示资源，不包含伪造截图

PDF 文件命名与 Markdown 报告保持对应关系，方便按节次提交或单独查看。导出 PDF 前，建议先检查每份报告的标题层级、基本信息、作业完成日期、图片路径和中文编码，确认内容符合老师要求后再导出。
